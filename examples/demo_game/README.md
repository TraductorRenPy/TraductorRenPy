# Demo game / Juego de ejemplo

A tiny Ren'Py project (original, harmless text) to try TraductorRenPy without using a real game.
Un proyecto Ren'Py mínimo (texto original e inofensivo) para probar TraductorRenPy sin usar un juego real.

**How to use / Cómo usarlo**

1. Copy this folder somewhere (the app writes the translation inside `game/tl/`).
   Copia esta carpeta a otro sitio (la app escribe la traducción dentro de `game/tl/`).
2. In TraductorRenPy choose the `demo_game` folder as the game folder. / En TraductorRenPy elige la carpeta `demo_game` como carpeta del juego.
3. Press **Translate this game automatically**. / Pulsa **Traducir este juego automáticamente**.

It contains tags (`{i}`, `{b}`), variables (`[player_name]`), a menu, a `renpy.input` prompt, a notification and
two screen texts that are not marked for translation, so every step of the tool has something to do.
Contiene etiquetas, variables, un menú, un `renpy.input`, una notificación y dos textos de pantalla sin marcar,
para que cada paso de la herramienta tenga algo que hacer.
