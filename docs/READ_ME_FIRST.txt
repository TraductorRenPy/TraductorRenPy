TraductorRenPy - READ ME FIRST (the essentials)
================================================

Translates games made with Ren'Py into other languages (neutral Spanish by default).

1) OPENING THE PROGRAM
   Extract the WHOLE folder from the .zip (right-click > Extract all) and open TraductorRenPy.exe.
   Do not run it from inside the .zip.

2) IF WINDOWS SHOWS "WINDOWS PROTECTED YOUR PC"
   This is expected: the program is free, open source, and has no paid digital signature,
   so Windows warns about any little-known program.
   Click "More info", then "Run anyway".
   All the code is published in the project repository if you want to review it.
   Your antivirus may warn too, for the same reason.

3) WHAT YOU NEED
   - The Ren'Py SDK (free): https://www.renpy.org/latest.html
     Download it, extract it and, in the window, press "Buscar SDK" (find SDK) or pick its folder.
   - An API key for a translation engine. The "Get key..." button opens the right page.
     Gemini has a free tier. Your key is stored encrypted, only on your computer.

4) TRANSLATING
   Pick the game folder, the language and the engine, paste your key and press
   "Translate this game automatically". If it stops (a daily limit, for example),
   press it again later: it continues where it left off, without repeating what is done.

5) HELP AND PROBLEMS
   - "Help" button inside the program.
   - "Report a problem" button: prepares a report WITHOUT paths, e-mails or keys; you review it
     before sending.
   - Feedback and questions: https://github.com/TraductorRenPy/TraductorRenPy/discussions
